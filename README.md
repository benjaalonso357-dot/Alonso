# Alonso
La carpeta buzo contiene la carpeta `.history`, varias carpetas de respaldo llamadas `_restore_backup_...`, la carpeta `ProyectoFinalRossiPuto`, el archivo de la placa electrónica de KiCad (`buzo.kicad_pcb`), el archivo de configuración local (`buzo.kicad_prl`), el archivo del proyecto (`buzo.kicad_pro`), el esquema eléctrico (`buzo.kicad_sch`) y varios archivos Gerber (`buzo-B_Cu.gbr`, `buzo-F_Cu.gbr`, `buzo-B_Mask.gbr`, `buzo-F_Mask.gbr`, `buzo-B_Silkscreen.gbr`, `buzo-F_Silkscreen.gbr` y `buzo-Edge_Cuts.gbr`), además del archivo `buzo-job.gbrjob`, que contiene información para la fabricación de la placa.

La carpeta Nueva carpeta contiene el archivo `jaja-drl.rpt`, que es un informe relacionado con las perforaciones de la placa electrónica.

La carpeta prueba del proyecto contiene el archivo temporal `~prueba del proyecto.kicad_sch.lck`, el archivo de configuración local `prueba del proyecto.kicad_prl`, el archivo de configuración del proyecto `prueba del proyecto.kicad_pro` y el esquema eléctrico `prueba del proyecto.kicad_sch`. Estos archivos corresponden a una versión de prueba del diseño realizado en KiCad.

La carpeta sketch_oct23a contiene el archivo `sketch_oct23a.ino`, que es el código fuente de Arduino donde se escriben las instrucciones para controlar los componentes electrónicos del proyecto.

El archivo README contiene información general e instrucciones sobre el proyecto, y sirve para explicar su contenido y facilitar que otras personas puedan entenderlo.
